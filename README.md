# Customer-Behavior-Analaysis
Data Analytics Project showcasing customer behavior analysis using Python, sql, power Bi.

# 📊 Customer Shopping Behavior Analysis

## Overview

This project demonstrates an end-to-end Data Analytics workflow using Python, SQL, and Power BI. The objective was to transform raw customer shopping data into meaningful business insights through data cleaning, exploratory data analysis (EDA), SQL-based analysis, and an interactive Power BI dashboard.

The project showcases practical data analytics skills, including data preprocessing, querying relational databases, creating visualizations, and presenting insights to support data-driven decision-making.

---

# 📁 Dataset

**Dataset:** Customer Shopping Behavior Dataset

The dataset contains customer purchase information, including demographics, purchasing patterns, payment methods, product categories, discounts, and subscription details.

# 🚀 Project Workflow

## 1. Data Loading

* Imported the dataset into Python.
* Examined the dataset structure, data types, and basic statistics.

## 2. Data Cleaning

* Removed duplicate records.
* Handled missing values.
* Renamed and standardized column names.
* Corrected inconsistent values.
* Created additional features for analysis where required.

## 3. Exploratory Data Analysis (EDA)

Performed exploratory analysis to understand customer behavior by:

* Age and Gender
* Product Categories
* Purchase Amount
* Review Ratings
* Subscription Status
* Discounts
* Payment Methods
* Seasonal Trends

Visualizations were created using Matplotlib and Seaborn to identify trends and patterns.

## 4. SQL Analysis

The cleaned dataset was imported into MySQL/PostgreSQL for business analysis.

SQL concepts used include:

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* HAVING
* CASE Statements
* Aggregate Functions
* Window Functions
* Common Table Expressions (CTEs)

Business questions were answered using SQL queries to extract actionable insights.

## 5. Power BI Dashboard

An interactive dashboard was built to present key metrics and business insights through dynamic visualizations.

# ▶️ How to Run

1. Clone this repository.
2. Install the required Python libraries:

   * pandas
   * numpy
   * matplotlib
   * seaborn
3. Open the Jupyter Notebook and run the data loading, cleaning, and EDA steps.
4. Import the cleaned dataset into MySQL or PostgreSQL.
5. Execute the SQL queries to perform business analysis.
6. Open the `.pbix` file in Power BI Desktop to explore the interactive dashboard.
